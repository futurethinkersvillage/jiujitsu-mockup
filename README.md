# Clearwater Jiu Jitsu & Judo — brand directions preview

Static site served by nginx on Coolify at https://jiujitsu.designspore.co

- `site/index.html` — compares the three brand directions
- `site/{tenugui,wellsgray,stripe}/` — homepage versions (generated by `python build/build_site.py`)
- `site/posters/` — 12 printable posters (18×24 in), themeable: `?theme=tenugui|wellsgray|stripe`, single poster `&p=<id>`
- `site/assets/content.js` — all poster content (Japanese terms, belts, etc.)
- `site/prompts/` — image prompts for each direction
- `site/research/` — competitor research
